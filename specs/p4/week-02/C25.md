## Bàn giao và chạy kiểm chứng

- Bên sử dụng: P3 tích hợp danh mục/UI và P2 tích hợp trang chi tiết. Output là mã API và contract trong PR#12; không yêu cầu bên nhận sinh lại embedding để đọc sách.
- Các endpoint: `GET /api/v1/books`, `/books/{book_id}`, `/facets`, `/books/{book_id}/chapters`, `/chapters/{chapter_id}`. Dùng `snapshot_id` khi cần giữ phiên bản đang đọc; cấu trúc response theo SPEC12.4/OpenAPI C03.
- Môi trường phục vụ cần `SNAPSHOT_ROOT` trỏ tới cây snapshot và `CONTROL_ROOT` chứa `active.json`; mỗi snapshot có `catalog.sqlite` và `manifest.json` hợp lệ. Thành phần FAISS C14 hoặc SQLite staging C10 riêng lẻ chưa phải snapshot phục vụ hoàn chỉnh. Không tự đổi trạng thái duyệt của dữ liệu nội bộ3.2.
- Mã đã có hàm ICU và dependency; khai báo dependency không đồng nghĩa `.venv` Windows đã cài thư viện. API danh mục dùng khóa BLOB đã tạo offline; facets cần PyICU thật để sắp tác giả. Thiếu PyICU trả503, không tự dùng thứ tự byte thay thế.
- Chốt API C25 bằng fixture kỹ thuật tự viết đúng schema và kiểm ICU thật; sách/toàn văn được duyệt, pipeline phát hành và nghiệm thu C29 được theo dõi riêng.

Từ root repo, trên máy có Docker Linux engine đang chạy:

```powershell
docker build --file api/tests/Dockerfile.c25 --tag smartlib-c25:verify api
docker run --rm --network none --read-only smartlib-c25:verify python -c "import icu; print(icu.VERSION, icu.ICU_VERSION, icu.UNICODE_VERSION)"
docker run --rm --network none --read-only --tmpfs /tmp:rw,nosuid,nodev --mount "type=bind,source=$PWD,target=/workspace,readonly" smartlib-c25:verify python -B -m pytest tests/test_catalog_reader.py tests/test_catalog_icu.py tests/test_health.py -q -p no:cacheprovider --basetemp /tmp/c25-pytest --tb=short -x
```

Job `c25-icu` trong GitHub Actions chạy cùng quy trình. Image trên chỉ dùng kiểm chứng C25, không thay image triển khai API. Test ICU gồm thứ tự tiếng Việt, dấu/chữ hoa, NFC/NFD, numeric OFF, dấu câu và facets/phân trang theo khóa lưu sẵn. Bộ test này skip ở máy thiếu PyICU; bước import bắt buộc trong CI ngăn coi skip là đạt nghiệm thu ICU.
