## Chạy frontend thật

Giải nén gói vào `data/demo/c29-real-20261121-final/`. Từ repo root, terminal API:

```powershell
$r = (Resolve-Path 'data/demo/c29-real-20261121-final').Path
$env:PYTHONPATH = "$PWD/api;$PWD/pipeline"
$env:SNAPSHOT_ROOT = "$r/snapshots"
$env:CONTROL_ROOT = "$r/control"
Remove-Item Env:SMARTLIBAI_DEMO_SNAPSHOT -ErrorAction SilentlyContinue
Remove-Item Env:CLASSROOM_DEMO_SNAPSHOT -ErrorAction SilentlyContinue
$env:GEMINI_API_KEY = ''
.\.venv\Scripts\python.exe -B -m uvicorn src.main:app --host 127.0.0.1 --port 8000
```

Terminal khác: `cd web`, `npm run dev`, mở `http://localhost:3000/read/B_acdaa0b8-2348-4cbb-b68c-0f75aa2bc51b?snapshot_id=c29-songchet-20261121` hoặc Khám phá→chỉ có toàn văn→chi tiết→Đọc sách. Nếu Vite báo cổng khác, dùng đúng cổng đó. Không thêm reader_fixture; dừng server cũ ở terminal của nó nếu cổng8000 đang bị dùng. Chỉ dùng biến môi trường trong terminal riêng.
