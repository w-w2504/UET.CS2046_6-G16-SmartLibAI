## 3. Hành vi chi tiết

- Route `/read/:book_id/:chapter_id?snapshot_id=...`; chưa có chapter thì nạp mục lục và chuyển sang chương đầu cùng phiên bản.
- Nạp mục lục và chương bằng client đúng cấu trúc SPEC. Snapshot đã nhận được giữ cho các lần chuyển chương; không tự đổi sang active nếu nguồn cũ mất.
- Mục lục theo thứ tự server, chương đầu/cuối vô hiệu hóa nút Trước/Sau tương ứng. Tên chương và đoạn được render như text an toàn.
- Đổi chương xóa phần nội dung cũ khỏi vùng đọc; loading, lỗi và retry chỉ tác động vùng tương ứng. Mã lượt/AbortController ngăn response cũ ghi đè. Retry không reload trang hoặc gửi QA.
- Request đọc timeout UI 12 giây theo SPEC 12.4; hiển thị lỗi và giữ đường dẫn/phiên bản.
- Fixture do nhóm/assistant tự viết, không dùng sách thật chưa được duyệt; chỉ bật chủ động với `reader_fixture=1` khi Vite chạy dev. Nhãn dữ liệu mẫu luôn hiện; lỗi API thật không tự chuyển fixture. Production loại nhánh fixture.
- Bố cục/màu/font/nút 44px theo SPEC 13.4; 390px một cột, mục lục thu/mở; 1280px mục lục và nội dung cùng khung chờ QA. Không làm chức năng QA trong tuần 1.

## 6. Chạy thử và kiểm chứng

```powershell
# Terminal 1, từ thư mục web:
npm ci
npm run dev -- --host 127.0.0.1 --port 3000 --strictPort
# Mở http://127.0.0.1:3000/read/B_reader_fixture?reader_fixture=1

# Terminal 2, từ thư mục web:
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort

# Terminal 3, từ thư mục gốc; dùng Python có Playwright:
python -B web/tests/check_reader_browser.py
```

Script kiểm tra cần Playwright Python và Edge cài trên máy. Lượt này dùng Playwright 1.60.0 đã có sẵn; không thêm dependency browser test vào ứng dụng. Trong môi trường khác, chuẩn bị công cụ kiểm thử tương ứng trước khi chạy.

Không có `reader_fixture=1` thì dev cũng gọi API thật. Production bỏ nhánh fixture; thêm tham số trên vào URL production vẫn không bật dữ liệu mẫu. API thật hiện chưa hoàn tất C25 nên không dùng demo fixture để kết luận tích hợp đã đạt.
